Their platform combines proprietary technology, non-intrusive monitoring, and a 24/7 expert support unit to promote personal autonomy at home and on the go.

**Key responsibilities and technologies:**
- Building and maintaining interfaces with **Vue.js 2/3** and **TypeScript**
- Developing real-time voice and communication features with **Asterisk**, **JsSIP**, **WebRTC**, and **WebSockets**
- Documenting UI components with **Storybook**
- Ensuring software quality with **Playwright** end-to-end tests
